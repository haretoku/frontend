見積もりを受け取ったら，すぐ契約するの？

はれトク博士

設備や工事の範囲，支払総額と時期，保証を説明してもらい，納得してから契約します．合意した内容は書面で確認し，保管しましょう．

ハレナ

補助金の申請は，契約したあとでいいのかな？

はれトク博士

制度によって手順が違います．契約前に公式情報と施工会社で，誰が・いつまでに・何をするか，どの段階から契約や工事を始められるかを確かめましょう．

ハレナ

工事が終わったら，そのまま使い始めていい？

はれトク博士

必要な手続きと動作確認を終え，使用開始の案内を受けてからです．使い方や停電時の対応も，説明してもらいましょう．

ハレナ

説明を聞いたあとも，分からないことが出てきそうだね．

はれトク博士

説明書・保証書と，点検や不具合のときの連絡先を受け取っておきましょう．

    条件と手順に納得し，合意内容を書面で確認・保管

  2. 工事

    確認した日程と手順に沿って，施工会社が設備を取り付ける

  3. 引渡し・使用開始

    必要な手続き・動作確認を済ませ，説明と使用開始の案内を受ける

見積もりをもらったら，断れない？
はれトク博士

見積もりを受け取ることと，契約することは別です．その場で決めず，条件を書面で確認しましょう．納得できなければ，導入を見送ることもできます．

補助金の申請は，施工会社に任せていい？
はれトク博士

施工会社に頼む場合も，どこまで代行するか，自分が用意する書類，申請・報告の期限を確認しましょう．自分が行うことと，会社に任せることを分けておくと安心です．

工事中，普段どおり家で過ごせる？
はれトク博士

工事内容や家の状況で変わるので，作業日程や在宅・立会いが必要かを施工会社に聞きましょう．停電があるか，いつ・どのくらい続くかも事前に確認します．
