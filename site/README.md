# site

## 役割

> **結論：siteは，公開画面・共通資産・画面仕様と，GitHub Pagesの成果物生成・検査を管理する．**

|場所|役割|
|---|---|
|`index.html`|TOPマップとGOAL・相談先への案内|
|`map/`|主要導線の会話・図・診断・進捗保存と，共通の描画・URL定義|
|`guides/`|主要導線14記事の正規URLと，既存ガイド9件・一覧・既存調査記事|
|`press/`|プレスリリース一覧（既存調査記事のURLは維持）|
|`solar/`|ガイド一覧の共通処理・メタデータ・スタイル|
|`simulator/`|マップに位置付けた診断の正規URL．計算共通部はsrc配下に保持|
|`pages/`|計算方法，運営方針|
|`articles/`|記事の採用値反映・固有表示・図表資産|
|`data/`|データ一覧・補助金データの表示|
|`shared/`|共通表示・スタイル・画像|
|`hosting/`|Pages成果物の最終処理・公開前検査|
|`docs/`|グランドデザイン，画面設計，補助金データ，実装方針|

## 公開設定

> **結論：本番とプレビューの成果物をGitHub Pages用へ統一し，公開操作は承認後に手動実行する．**

通常開発はfrontendルートの`.config/vite.config.js`，構築とプレビューは`.config/vite.pages.config.js`を使う．`hosting/finalize-pages.js`が`dist-pages/`を整え，`verify-pages.js`が公開範囲・参照資産・データ一致・内部資料の非混入を検査する．手順は[実装方針](docs/実装方針.md#ローカル開発)，公開版の識別は[タグ規則](../README.md#コミットタグと公開の区別)に従う．
