## ページの分類

> **結論：公開ページを，はれトクガイド，診断情報および運営ポリシーに分け，ガイド記事だけを記事ジャンルへ分類する．**

公開コンテンツ3種類の目的，内容，入口および次の導線と，ガイド記事4分類は[グランドデザイン](../docs/グランドデザイン.md#情報設計とページの責務)を正本とする．ガイド記事は「収支」「補助金」「見積もり」「災害への備え」のいずれか1つへ分類する．診断情報と運営ポリシーは記事ではなく，ガイド一覧に表示しない．トップには4分類に対応する代表4記事を表示する．

ガイド記事5件は，`article--guide`による1カラムの共通構造を用いる．表示順，見出し階層，目次および診断・見積もり導線の主従は[画面設計](../docs/画面設計.md#ガイド記事の本文構造)を正本とする．`calculation-method.html`と`policy.html`にはこの一般記事テンプレートを適用しない．

| ファイル | 公開コンテンツの種類 | ガイドでの分類・表示 |
|---|---|---|
| `calculation-method.html` | 診断情報 | ガイド一覧へ表示しない |
| `policy.html` | 運営ポリシー | ガイド一覧へ表示せず，フッターから各方針へ接続する |
| `costs-maintenance.html` | はれトクガイド | 収支 |
| `electricity-sales.html` | はれトクガイド | 収支 |
| `subsidies.html` | はれトクガイド | 補助金 |
| `disaster.html` | はれトクガイド | 災害への備え |
| `quotes-contractors.html` | はれトクガイド | 見積もり |

将来の「設備・製品」は，個別製品を継続して更新・検証できる体制が整ってから追加する．「パネル比較」は独立分類ではなく，「設備・製品」の記事形式として扱う．

## 記事の送客カード

> **結論：診断と外部見積もりの送客カードは共通形状とし，役割色と広告表示で区別する．**

通常ガイド5記事の見積もり操作はPC・スマートフォンとも共通固定バーへ集約する．本文には確認事項を短く残し，重複ボタンや空CTA枠を置かない．対象記事，導入末尾の開始位置，操作保護，共通送客設定および安全余白は[画面設計](../docs/画面設計.md#固定見積もりバー)を正本とする．内部の診断リンク，目次・出典・関連記事は保持する．計算方法・使用データと運営ポリシーは固定バーの対象外とする．

## 不利益情報から確認までの流れ

> **結論：重要な不利益情報を保持したうえで，変更可能な代替，別の価値，確認行動および導入見送りを示す．**

赤字，未回収または条件不適合等の重要な注意は，強調を薄めたり隠したりしない．注意の後には，設備容量，設備構成または見積価格等，利用者が変更できる条件を必要な範囲で示す．防災等の価値を扱う場合は経済的回収と分け，設備ごとの制約を混同せず，必要な機能を満たすか専門事業者へ確認する流れとする．代替案が採算改善や目的達成を保証するとは表現せず，導入見送りも妥当な選択として残す．CTAを追加せず，既存の診断・外部見積もり送客カードへ接続する．
