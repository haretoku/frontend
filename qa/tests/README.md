# tests

Node.js標準のテストランナーで，公開サイトの計算・表示構造・導線・データ接続を検査する．`pnpm run test:public`は公開画面・計算，`pnpm run test:data`は補助金一覧・接続，`pnpm test`は両方を実行する．必要なGit LFS fixtureを取得してから検査する．

## 検査範囲

> **結論：現行の計算・データ契約と公開導線を検査し，過去の版番号や件数を合格条件に代用しない．**

- 全国47都道府県・入力境界とbackend基準計算の一致．
- 制度適格性，受付・非算入理由，併用，容量・費目・控除・丸め順，nullと確認済み0円の区別．
- 30年評価，需給保存，劣化，交換費，年間図表・記事の数値同期．
- トップ・診断入力，URL復元，記事・目次・内部リンク・図表DL・広告導線．
- 補助金一覧・自治体コード・公式情報リンクと公開データの対応．
- GA4の本番限定送信と入力情報の非送信．

自動検査は実画面・一次資料の検収を代替しない．対象版の識別，変更影響とPC・スマートフォンの確認範囲は[QA正本](../README.md)に従う．継続して必要なケースはテストと`../fixtures/`へ保存し，旧版の実行ログを並行管理しない．
