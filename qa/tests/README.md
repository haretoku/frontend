# tests

Node.js標準のテストランナーで，公開サイトの計算・表示構造・導線・データ接続を検査する．`pnpm run test:public`は公開画面・計算，`pnpm run test:data`は補助金一覧・接続，`pnpm test`は両方を実行する．必要なGit LFS fixtureを取得してから検査する．

## 検査範囲

> **結論：現行の計算・データ契約と公開導線を検査し，過去の版番号や件数を合格条件に代用しない．**

- 全国47都道府県・入力境界とbackend基準計算の一致．
- 制度適格性，受付・非算入理由，併用，容量・費目・控除・丸め順，nullと確認済み0円の区別．
- 30年評価，需給保存，劣化，交換費，年間図表・記事の数値同期．
- トップ・診断入力，URL復元，記事・目次・内部リンク・図表DL・広告導線．
- 補助金一覧・自治体コード・公式情報リンクと公開データの対応．
- GA4の本番限定送信と入力情報の非送信．

自動検査は実画面・一次資料の検収を代替しない．対象版の識別，変更影響とPC・スマートフォンの確認範囲は[QA正本](../README.md)に従う．継続して必要なケースはテストと`../fixtures/`へ保存し，旧版の実行ログを並行管理しない．

## 共通実行と地域ケース

> **結論：全test.jsを単一の入口で各1回実行し，地域条件と独立したbackend期待値を保持する．**

`../run-tests.mjs`が`tests/*.test.js`を列挙する．`pnpm test`は全件，`test:public`と`test:data`は同じ一覧を役割で分けた検査であり，失敗は終了コードへ反映する．別テストの副作用importによる実行はしない．整理前の76本は直接入口14本＋間接読込み24本＋未実行38本であった．入口外のケースも共通入口へ含める．

`../helpers/subsidy-fixture.js`へデータ読取り・標準入力を集約する．北海道の保存済み5fixtureは変更せず，`subsidy-backend-vectors.test.js`で共通に照合する．国・県の独立期待値との配賦検査は`../helpers/`へ分離する．地域の金額・容量境界・依存・排他・費目条件は保持し，市単独の適格性と国県を含む最大組合せを区別する．未確定県制度を正額へ補完しない．依存・排他の正額分岐は，公式制度とは区別した合成条件でも検査する．

`municipal-formula.js`は地域共通の自治体算式，`retained-diagnostic-display*.js`は保存済み市区町村表示文型である．受領JSONの列・enum及び既存export名は契約として保持する．
