## 再生成

> **結論：配信用コピー，ロゴ，faviconを決まった手順で生成する．**

1. `node qa/generate-character-assets.mjs`で原本を既存の配信先へコピーし，ハレナの余白を除いたロゴ用`site/map/assets/sun-face.svg`を生成する．記事・勲章と同じ原本を1280×1280の面に配置し，表示窓`220 225 820 820`で周囲の余白を調整する．光の先端を欠かさない余白を残す．SVG内には原本から書き出した256×256 PNGを埋め込み，外部画像への依存を残さない．
2. `node qa/generate-favicon.mjs`で同じSVGと96×96 PNGを生成する．検索用URLは`/favicon.png`を保持する．
3. 16・32・96 pxの見え方と，標準・確認用ビルドを確認する．

書出しには既存の画像生成補助スクリプトと同様に`sharp`を使う．通常のモジュール解決，または`HARETOKU_SHARP_MODULE`で読み込む．原本はビルド配布の対象に加えない．
