# pages

計算結果の根拠と，金銭以外の判断材料を説明する詳細ページを置く．

| ファイル | 役割 |
|---|---|
| `calculation-method.html` | 計算式，前提および限界 |
| `costs-maintenance.html` | 初期費用，維持管理および交換費 |
| `electricity-sales.html` | 電気料金削減，FITおよび卒FIT |
| `subsidies.html` | 補助金の計算上の取扱いと適用条件 |
| `disaster.html` | 停電時の利用，蓄電池との違いおよび災害時の安全 |
| `quotes-contractors.html` | 正式見積もりの必要性と施工業者の確認項目 |

記事量を目的とせず，計算結果の各項目から必要な根拠へ直接移動できる構成とする．
